Machine Learning & Data Science

Data-Centric Land Cover Classification

Label Noise Ranking via Fine-Tuned SAM & SAM2 Geospatial Auto-Segmentation

A seven-step Kaggle competition pipeline that ranks satellite training patches by their level of label noise — not by building the best model, but by identifying which labels are most trustworthy. Uses a fine-tuned Segment Anything Model (SAM) and a SAM2 geospatial auto-segmentation model to score and rank each training patch.

Urban Utility Network Explorer

Satellite + Street-Level Intelligence for Bengaluru's Power Grid

An end-to-end Python GIS pipeline that downloads real OSM utility infrastructure data for Bengaluru, enriches it with satellite imagery from Google Earth Engine, and serves interactive analysis through a Streamlit dashboard — network tracing, flood risk, vegetation encroachment, and terrain analysis all in one command.
