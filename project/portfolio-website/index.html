Personal Portfolio Website

Multi-Page Academic Portfolio with Flask & Static Site Generation

View Code Live Demo

Overview

A professional, statically-generated academic portfolio built with Flask and Frozen-Flask. Features multi-page layouts, data-driven content from JSON, responsive design, and dual deployment to GitHub Pages and Netlify via GitHub Actions.

Project Details

A full-stack portfolio website that demonstrates modern web development practices. Built with Flask for dynamic route generation and Frozen-Flask for static site compilation, the portfolio serves content from JSON data files ensuring separation of concerns. The site features a responsive design with custom CSS, JavaScript interactivity, and optimized asset delivery. Deployment is fully automated — every push to the main branch triggers GitHub Actions to rebuild the static site and deploy to both GitHub Pages and Netlify. Includes security headers (X-Frame-Options, X-XSS-Protection, X-Content-Type-Options) and asset caching strategies.

Technologies Used

Python Flask Frozen-Flask Jinja2 HTML5 CSS3 JavaScript JSON GitHub Actions GitHub Pages Netlify Git

Key Features

  • Multi-page layout: home, about, projects, publications, contact, CV views
  • Data-driven architecture: all content sourced from JSON (profile, projects, CV data)
  • Responsive design with custom CSS and JavaScript
  • Interactive project filtering and detailed project pages
  • Publication showcase with type, year, and citation tracking
  • Contact form integration with Netlify Forms
  • CV download and inline viewer
  • Dual deployment: GitHub Pages (via Actions) + Netlify (automatic)
  • Security headers: X-Frame-Options, X-XSS-Protection, X-Content-Type-Options
  • Asset caching: 1-year immutable cache for static resources
  • Search engine optimization (SEO) ready

Outcomes & Impact

  • Live production site deployed across two platforms
  • Fully automated CI/CD pipeline with GitHub Actions
  • 100% static site — no server overhead, instant load times
  • Mobile-responsive design serving all device types
  • Customizable data structure allowing easy content updates
