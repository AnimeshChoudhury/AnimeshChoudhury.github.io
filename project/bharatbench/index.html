BharatBench

A Benchmark Dataset for Data-Driven Weather Forecasting over India

View Code Read Paper Live Demo

Overview

A ready-to-use dataset and benchmarking framework designed to accelerate data-driven weather forecasting research over India. Derived from IMDAA reanalysis with pre-processed, ML-ready data optimized for limited computational resources.

Project Details

BharatBench addresses the gap in regional weather forecasting research by providing a high-quality dataset specifically tailored to the Indian monsoon region. Unlike global datasets like WeatherBench (ERA5), BharatBench focuses on the meteorologically distinct Indian subcontinent with complex orography (Himalayas, Western Ghats) and diverse microclimates. The dataset spans 31 years (1990–2020) with 6-hourly temporal resolution, covering surface variables (2m temperature, wind, pressure, precipitation) and 13 pressure levels. With a 32×32 grid at 1.08° resolution, it is trainable on standard laptop CPUs. Complete benchmarks are provided: persistence, climatology, weekly climatology, linear regression, CNN, and ConvLSTM baselines with evaluation code.

Technologies Used

Python TensorFlow Jupyter Notebooks Xarray NetCDF Machine Learning Deep Learning CNN ConvLSTM IMDAA Reanalysis Weather Forecasting

Key Features

  • 31-year IMDAA-derived reanalysis dataset (1990–2020)
  • Regional focus: 5°N–40°N, 65°E–100°E with 1.08° spatial resolution
  • 6-hourly temporal resolution with 13 pressure levels (50–1000 hPa)
  • Surface variables: 2m temperature, 10m wind components, sea-level pressure, precipitation
  • Pressure-level variables: geopotential height, temperature, humidity, wind components
  • Pre-processed and ML-ready — 32×32 grid points for low compute barrier
  • Trainable on standard laptop CPU (Intel i7 / 32 GB RAM sufficient)
  • Complete baseline implementations: persistence, climatology, linear regression, CNN, ConvLSTM
  • Standard evaluation metrics: RMSE, MAE, Anomaly Correlation Coefficient (ACC)
  • Train/Val/Test split: 1990–2017 / 2018 / 2019–2020
  • Kaggle dataset and Jupyter notebook tutorials included

Outcomes & Impact

  • Published research paper on arXiv
  • Publicly available Kaggle dataset
  • Comprehensive benchmark results for 3-day and 5-day lead times
  • 4 Jupyter notebooks with complete reproducible code
  • Baseline CNN model achieves 26.27 RMSE vs. 28.47 climatology baseline
  • ConvLSTM baseline achieves 26.87 RMSE, capturing temporal dynamics
