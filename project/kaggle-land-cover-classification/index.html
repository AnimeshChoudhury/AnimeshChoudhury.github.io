Machine Learning & Data Science · 2024

Data-Centric Land Cover Classification

Label Noise Ranking via Fine-Tuned SAM & SAM2 Geospatial Auto-Segmentation

View Code Live Demo

Overview

A seven-step Kaggle competition pipeline that ranks satellite training patches by their level of label noise — not by building the best model, but by identifying which labels are most trustworthy. Uses a fine-tuned Segment Anything Model (SAM) and a SAM2 geospatial auto-segmentation model to score and rank each training patch.

Project Details

This project tackles the Kaggle Data-Centric Land Cover Classification Challenge, where the objective is to rank training samples by label noise rather than maximise model accuracy. The pipeline consists of seven ordered notebooks: (1) Data Visualization to explore patches and define a PyTorch SegmentationDataset; (2) Fine-tuning facebook/sam-vit-base with DiceCE loss for 10 epochs, producing per-image IoU scores; (3) Threshold Scoring to batch-run inference and export IoU CSVs; (4) Ranking Model Setup to convert (image, mask) pairs into 4-channel tensors for a DataLoader; (5) SAM2geo Auto-Segmentation using segment-geospatial to generate agreement-ratio scores; (6) SAM2 Threshold Scoring to refine per-image scores; and (7) Combined Score Ranking that merges both score streams, trains a small UNet regressor, and outputs the final submission. The combined score formula (IoU × (1 + 0.1 × auto_score)) rewards samples that both models agree are clean, placing cleaner labels earlier in the ranking.

Technologies Used

Python PyTorch Hugging Face Transformers Segment Anything Model (SAM) SAM2 / segment-geospatial MONAI Jupyter Notebook NumPy Pandas Scikit-learn Pillow Matplotlib CUDA

Key Features

  • Seven-notebook end-to-end pipeline from raw patches to final submission CSV
  • Fine-tuned facebook/sam-vit-base (mask decoder only) with DiceCELoss over 10 epochs
  • Per-image IoU scoring pipeline with batch inference and CSV export
  • SAM2 geospatial auto-segmentation for independent agreement-ratio scoring
  • 4-channel tensor DataLoader for UNet ranking regressor training
  • Combined noise score: IoU × (1 + 0.1 × auto_score)
  • Dual-model consensus — images both models agree are clean ranked highest
  • Reproducible: pinned requirements.txt and sequential notebook execution order
  • GPU-accelerated (CUDA) for all inference and training loops

Outcomes & Impact

  • Produced submission_33.csv — final ranked image list for Kaggle evaluation
  • Demonstrated a data-centric approach to label-noise detection in satellite imagery
  • Achieved dual-model score fusion (SAM + SAM2) for more robust noise estimation
  • Built a reusable PyTorch SegmentationDataset for land cover patch datasets
  • Established a template pipeline for label-noise ranking in geospatial ML challenges
