GEE Utilities

Curated Google Earth Engine Scripts & Notebooks for Geospatial Analysis

View Code

Overview

A curated collection of lightweight, self-contained Google Earth Engine utility scripts and Jupyter notebooks covering essential geospatial workflows — from Land Surface Temperature estimation and LULC classification to spatial sampling, raster-to-vector conversion, and temporal image filtering.

Project Details

GEE_Tools is a practical, open-source toolkit built to streamline recurring geospatial operations in Earth observation research. Each utility is independently usable, requiring no inter-script dependencies. The collection spans both the GEE JavaScript Code Editor and the Python API via Jupyter notebooks. Workflows include: randomized spatial sampling with configurable buffer zones, Landsat 8 Land Surface Temperature retrieval using split-window and single-channel algorithms, date-driven satellite image selection and compositing, raster-to-vector format conversion using GeoPandas and Rasterio, study area boundary definition and Folium-based visualization, and supervised LULC classification using GEE's built-in ML classifiers (Random Forest, SVM, CART). The toolkit is designed for reproducibility — all scripts are self-documented and ready to run after GEE authentication and a single pip install.

Technologies Used

Google Earth Engine Python JavaScript Jupyter Notebook Landsat 8 GeoPandas Rasterio NumPy Pandas Folium Random Forest SVM CART

Key Features

  • Random Points Buffer (01): Randomized spatial sampling with configurable buffer radii for field survey design
  • LS8 LST Estimation (02): Land Surface Temperature retrieval from Landsat 8 thermal bands using GEE JavaScript
  • Date-Wise Image Selection (03): Temporal satellite image filtering and compositing by custom date ranges
  • Raster to Vector (04): Automated conversion of raster outputs to vector formats (Shapefile/GeoJSON) using GeoPandas
  • Study Area Map (05): Interactive boundary definition and choropleth visualization with Folium
  • LULC GEE ML (06): Supervised Land Use/Land Cover classification using GEE's Random Forest, SVM, and CART classifiers
  • Each utility is self-contained — no inter-script dependencies
  • Supports both GEE JavaScript Code Editor and Python API workflows
  • MIT licensed and open for community contributions

Outcomes & Impact

  • 6 production-ready geospatial utilities covering the full RS processing pipeline
  • Reduces repetitive boilerplate in Earth observation research workflows
  • Supports studies in thermal analysis, land cover change detection, and spatial sampling
  • Jupyter notebooks are reproducible with a single pip install + GEE authentication
  • Dual-environment support: GEE Code Editor (JS) and Python API (Jupyter)
