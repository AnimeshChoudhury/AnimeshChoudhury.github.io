Anemoi Beginner Tutorial

A Beginner's Guide to ECMWF's Open-Source AI Weather Forecasting Toolkit

View Code

Overview

A beginner-friendly, ten-notebook scaffold for learning Anemoi — ECMWF's open-source toolkit for AI weather-model experimentation and forecasting — covering datasets, graphs, models, transforms, training, and inference, designed to run entirely on free-tier Colab CPU.

Project Details

AnemoiTutorial walks machine-learning beginners through the major Anemoi ecosystem concepts across ten sequential notebooks: environment setup and orientation, an ecosystem deep dive, a quick-win inference run on a pretrained AIFS model, exploring Anemoi datasets, training a first model, building graphs, understanding model architectures, applying transforms and filters, an end-to-end mini project, and next steps. The series is deliberately kept small and fast so the entire path — including training and inference — runs on CPU in a free-tier Google Colab session; only running the full-scale AIFS checkpoint locally requires a GPU with flash-attn, and that is an explicitly commented-out, optional path. A Drive-backed shared folder structure preserves checkpoints and outputs between Colab sessions to work around free-tier disconnects.

Technologies Used

Python Anemoi ECMWF AIFS PyTorch Jupyter Notebook Google Colab Google Drive API

Key Features

  • Ten sequential notebooks: setup & orientation, ecosystem deep dive, quick-win pretrained inference, exploring datasets, training your first model, graphs, models, transforms & filters, end-to-end mini project, next steps
  • Fully CPU-friendly — the whole series, including training and inference, is designed to run on a free-tier Colab session
  • Quick-win notebook downloads ECMWF's already-computed AIFS forecast output, needing no GPU at all
  • Optional, clearly commented-out GPU paths in later notebooks for learners who want to try them
  • Drive-backed shared environment helper that checkpoints progress across Colab session disconnects
  • Both Colab and local (conda) setup paths supported

Outcomes & Impact

  • End-to-end beginner path from environment setup to a working mini forecasting project using Anemoi
  • Hands-on familiarity with Anemoi datasets, graphs, model configuration, and training/inference workflows
  • Zero-GPU-required learning path validated for free-tier Google Colab
  • Reusable scaffold for onboarding new researchers to ECMWF's AIFS / Anemoi ecosystem
