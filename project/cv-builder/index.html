Academic CV Builder

Python-Based PDF CV Generator for Researchers

View Code

Overview

A Python tool that generates publication-ready academic CVs from a single JSON data file. Features a clean, professional layout with embedded profile images, clickable social icons, and DOI/URL hyperlinks — all without requiring LaTeX or manual PDF formatting.

Project Details

CV_Builder streamlines the process of creating and maintaining academic CVs. Instead of manually formatting a resume in Word or LaTeX, researchers simply edit a single JSON file containing their profile, experience, education, publications, and skills. The tool uses ReportLab to programmatically generate a polished PDF with precise layout control. Key features include profile image embedding with automatic square-cropping, clickable social profile icons (email, phone, LinkedIn, GitHub, Google Scholar, ResearchGate) in the header, and embedded hyperlinks for publication DOIs and URLs. Work experience entries are automatically sorted chronologically with current roles pinned at the top. The modular architecture makes it easy to add, remove, or reorder CV sections.

Technologies Used

Python ReportLab PIL/Pillow JSON PDF Generation Automation

Key Features

  • JSON-driven architecture — edit a single file, no code changes needed
  • Profile image embedding with automatic square-crop
  • Clickable social icons in the header (email, phone, LinkedIn, GitHub, Scholar, ResearchGate)
  • Embedded hyperlinks: clickable DOI links for publications, URL links for conference papers
  • Auto-sorted work experience — entries chronologically ordered by end date, current roles at top
  • Modular section rendering — each CV section as an independent method
  • Customizable styling: fonts, sizes, colors via Python code (primary, secondary, text, accent colors)
  • Pre-defined CV styles for consistency: CVName, CVTitle, CVContact, CVSectionHeading, CVBody, CVPublication, CVJobTitle, CVOrganization, CVBullet
  • Support for multiple entry types: journals, conference papers, posters, training, webinars
  • Auto-generated footer with 'Last updated' timestamp
  • Fully customizable — maintain separate JSON files for different application contexts (academic vs. industry CVs)

Outcomes & Impact

  • Single-command CV generation: python cv_builder_final.py
  • Publication-ready PDF output with professional typography
  • Version-controlled CV content via JSON
  • Significantly faster CV updates compared to manual formatting
  • Reusable tool for creating multiple CV variants
