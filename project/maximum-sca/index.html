Maximum Snow Cover Area — NW Himalaya

Monthly Maximum Snow Cover Extent Analysis of the Northwest Himalayan Region (2000–2020)

View Code Read Paper

Overview

A 20-year (2000–2020) analysis of monthly maximum Snow Cover Area (SCA) over the Northwest Himalaya using MODIS/Terra MOD10A2 V6 satellite data. Implements a multi-tile mosaicking, reprojection, and pixel-wise monthly maximum snow detection pipeline — underpinning a peer-reviewed Remote Sensing journal publication.

Project Details

The Northwest Himalaya (NWH) is one of the world's most climatically sensitive regions, acting as the primary freshwater reservoir for millions of people through snow and glacier melt. This study built an end-to-end satellite data processing pipeline using the MODIS/Terra Level-3 8-day composite Snow Cover product (MOD10A2 V6, 500 m resolution) spanning March 2000 to February 2020. The spatial domain covers four MOD10A2 tiles (h23v05, h24v05, h24v06, h25v06) representing the full Northwest Himalayan extent. The pipeline performs: (1) date-sorted file organisation from NASA Earthdata, (2) four-tile mosaic generation per 8-day period, (3) reprojection to EPSG:4326, (4) rectangular clipping to study area bounding box, (5) precise boundary clipping via shapefile, and (6) monthly maximum SCA computation — where any pixel recording DN=200 (snow) in at least one 8-day observation within a month is classified as snow. This conservative maximum approach reduces cloud contamination bias. Results were published in a peer-reviewed article in Remote Sensing (MDPI, Q1 journal) exploring the response of NWH snow cover dynamics to climate variability.

Technologies Used

Python Jupyter Notebook MODIS MOD10A2 V6 NumPy Rasterio GeoPandas GDAL NASA Earthdata EPSG:4326 Matplotlib

Key Features

  • 20-year MODIS snow cover time series: March 2000 – February 2020
  • Four-tile mosaic pipeline covering the full Northwest Himalayan extent (h23v05, h24v05, h24v06, h25v06)
  • 500 m spatial resolution using MOD10A2 V6 Level-3 8-day composite product
  • DN-class-aware pixel filtering: snow (DN=200), cloud (DN=50), lake ice (DN=100), no-snow (DN=25)
  • Monthly maximum SCA: pixel marked snow if any 8-day observation within the month shows DN=200
  • Automated date-based file sorting from NASA Earthdata filenames
  • Shapefile-based precise boundary clipping (bounding box + exact polygon)
  • Reprojection pipeline: native sinusoidal → EPSG:4326
  • Backed by a peer-reviewed Remote Sensing (MDPI) journal publication

Outcomes & Impact

  • Published in Remote Sensing 2021, 13(4), 655 (MDPI — Q1 journal)
  • Quantified 20-year snow cover dynamics across the Northwest Himalaya
  • Demonstrated the climate sensitivity of NWH snow cover to temperature and precipitation variability
  • Provided a reproducible Python pipeline for MODIS SCA analysis
  • Contributed to regional water resource and hydropower planning research
