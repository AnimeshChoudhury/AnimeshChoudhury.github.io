Urban Utility Network Explorer

Satellite + Street-Level Intelligence for Bengaluru's Power Grid

View Code

Overview

An end-to-end Python GIS pipeline that downloads real OSM utility infrastructure data for Bengaluru, enriches it with satellite imagery from Google Earth Engine, and serves interactive analysis through a Streamlit dashboard — network tracing, flood risk, vegetation encroachment, and terrain analysis all in one command.

Project Details

Urban utility networks are increasingly vulnerable to climate-driven risks. This project builds a reproducible, production-ready GIS pipeline integrating OpenStreetMap infrastructure data with four Google Earth Engine satellite datasets (DynamicWorld LULC, SRTM terrain, Sentinel-2 NDVI, and JRC Global Surface Water). The core analysis identifies which substations lie in flood-prone zones, which power lines face vegetation encroachment risk, and which grid segments cross steep terrain. A Streamlit dashboard with Folium interactive maps, network graph tracing (Dijkstra), and outage simulation visualizes the full risk picture. The pipeline runs end-to-end with a single command and includes a synthetic offline demo mode requiring no GEE authentication.

Technologies Used

Python Google Earth Engine Streamlit GeoPandas OSMnx NetworkX Folium Sentinel-2 SRTM JRC Global Surface Water Rasterio Geemap Dijkstra Shortest Path

Key Features

  • Live OSM data download — real power lines, substations & towers for Bengaluru
  • 500 m service-area buffer analysis and spatial joins
  • Network graph model with Dijkstra shortest-path tracing
  • GEE flood risk mapping (JRC GSW) — 50.6% of substations in flood-prone zones
  • Sentinel-2 NDVI vegetation risk — 188 km of lines at encroachment risk
  • SRTM terrain slope analysis — 321 km of lines crossing steep terrain (>15°)
  • 5-tab interactive Streamlit dashboard with toggleable satellite + OSM layers
  • Offline synthetic demo mode — no GEE account needed
  • Fully reproducible: pinned dependencies, deterministic seed (seed=42), EPSG:4326 / UTM 43N

Outcomes & Impact

  • Identified 89 of 176 substations (50.6%) in flood-prone zones
  • Flagged 188 km of power lines at vegetation encroachment risk
  • Detected 321 km of grid lines crossing steep terrain (>15° slope)
  • Integrated 4 GEE satellite datasets with real-time OSM network data
  • Built end-to-end pipeline runnable with a single command

Satellite Datasets (Google Earth Engine)

Four GEE datasets power the risk intelligence layer of this project, each processed through a dedicated analysis script with both live GEE and synthetic offline demo modes.
