NISAR Tutorial

Hands-On SAR & InSAR Analysis with Real NISAR Mission Data

View Code

Overview

A hands-on Python tutorial for working with NASA-ISRO SAR (NISAR) mission data, built entirely on five real NISAR sample products (RSLC, GCOV, and GUNW; L-band and S-band) — teaching SAR and InSAR techniques such as multilooking, backscatter differencing, polarimetric ratios, and coherence-based masking using real data throughout.

Project Details

Seven progressive Jupyter modules take a learner from SAR theory to applied InSAR analysis on five real NISAR RSLC/GCOV/GUNW products (L-band and S-band). Module 00 is a standalone theory primer covering geometry, speckle statistics, scattering mechanisms, polarimetry, and InSAR phase; Modules 01-06 build on real data readers (band/product auto-detection in nisar_tools/io.py) to demonstrate reading complex SLC data, repeat-pass change detection, GCOV HH/HV polarimetric ratios, InSAR deformation basics, and L-band vs. S-band comparison. The repo is explicit about scope: it is a technique demonstration, not a validated case study — no flood, subsidence, or land-cover claim is asserted without ground truth, and a dedicated 'Lessons learned' section documents cases where a first-pass result looked plausible (e.g. an apparent meter-scale deformation signal, or spurious spatial structure in a correlation map) but turned out to be a calibration artifact or an estimator-bias effect once checked against theory.

Technologies Used

Python h5py NumPy SciPy Matplotlib Xarray Rioxarray Rasterio GeoPandas Shapely PyProj Cartopy Folium Jupyter Notebook pytest

Key Features

  • Seven-module progression: theory primer → RSLC fundamentals → repeat-pass change detection → GCOV polarimetric ratios → InSAR deformation basics → L/S-band comparison → S-band polarimetric exploration
  • Product readers that auto-detect band and product type (RSLC/GCOV/GUNW) from each file's own HDF5 metadata rather than hardcoded per-file logic
  • Real SAR/InSAR techniques throughout: multilooking, backscatter differencing, HH/HV ratio computation, coherence-based masking, dual-pol correlation, cross-band comparison
  • Full metadata inventory and data-access guide (ASF DAAC for L-band, ISRO Bhoonidhi for S-band) since the large real .h5 files themselves are not redistributed
  • 'Lessons learned' table documenting plausible-looking first-pass results that turned out to be calibration or estimator-bias artifacts, checked in place rather than scrubbed out
  • Smoke tests (tests/test_io.py) verifying product readers against the real sample files

Outcomes & Impact

  • Working, auto-detecting readers for NISAR RSLC, GCOV, and GUNW products
  • Demonstrated repeat-pass change detection and InSAR deformation workflows on real L-band NISAR data
  • Cross-band (L vs. S) backscatter comparison over a confirmed shared footprint
  • Documented and explained two statistical traps (speckle CV bias, correlation estimator bias) with synthetic and real-data checks
  • Reusable reference for the SAR/InSAR community ahead of full NISAR mission data availability
